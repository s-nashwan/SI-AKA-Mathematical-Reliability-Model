# Release v1.0

This release contains the reproducibility package for the mathematical reliability analysis of SI-AKA synchronization.

It includes the mathematical source code, automated tests, numerical result files, Monte Carlo validation, burst loss analysis, active suppression analysis, and the source files used to regenerate the numerical figures reported in the study.

The package does not modify the original SI-AKA authentication protocol. It reproduces only the mathematical models and numerical results described in the paper.
